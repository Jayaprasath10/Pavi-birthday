# Pavi Birthday Website — V2 ❤️

A cinematic, mobile-friendly birthday experience built with HTML, CSS and JavaScript.

## V2 features
- Magical animated intro and gift opening
- Floating hearts and star particles
- Interactive balloon popping celebration
- Existing memory videos preserved
- Animated birthday cake and candle wish
- Confetti celebration
- Interactive envelope and typewriter letter
- Falling petals
- Fireworks finale
- Replay experience
- No build tools or backend required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Push all files and the `assets` folder to your GitHub repository, then enable GitHub Pages from:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
