# Pavi Birthday Website ❤️

A romantic interactive birthday page for Pavi.

## Files
- index.html
- style.css
- script.js
- assets/pavi.png
- assets/moment-1.mp4
- assets/moment-2.mp4
- assets/moment-3.mp4

## Run
Open `index.html` in a browser. The new Favorite Moments section contains all three uploaded videos.

## GitHub Pages
Upload all files to a GitHub repository, keeping the `assets` folder in the same location as `index.html`, then enable GitHub Pages from the repository settings.
